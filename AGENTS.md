# Agent Instructions

`CLAUDE.md` is the canonical repository guide for all coding agents. Read it
in full before changing this repository and follow every applicable rule.

When `CLAUDE.md` routes a task to a guide under `.claude/skills/`, read the
relevant `SKILL.md` in full before editing. Run the checks in
`.claude/skills/pre-pr-verification/SKILL.md` before handoff.

Keep this file as a pointer so repository instructions have one source of
truth. Update `CLAUDE.md`, not this file, when the shared rules change.
