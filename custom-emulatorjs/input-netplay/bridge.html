    Windows launcher & core setup

    Download once and run Register Launcher.cmd. Then choose Windows RetroArch and Join game in the room. Keep this page open while playing.

    Download Windows launcher (first setup)

    No administrator access is needed. The launcher uses a matching RetroArch installation or downloads a portable copy. It sets up the core, cartridges and your selected save automatically.

    Download matching core

    Download core info (.info)

    Also copy the .info file into the folder shown under RetroArch Settings → Directory → Core Info. Close RetroArch, remove core_info.cache from that folder if present, then reopen it. Select the matching core under Load Core, then choose your game under Load Content.

    mGBA: the Windows session prepares every cartridge in the room's order. For manual loading, use the GBA Link subsystem with that same order. Loading one GBA file repeats it in every slot.

    Playing and saving

    Open Netplay during web play to see this room. Return to game keeps playing; Save and return to room closes your game and keeps your place. Ping beside each name is the round-trip time to the server.
