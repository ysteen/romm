Game Boy Link Lab

Two cartridges. One link cable. Both players run the games locally.

01 Player one

02 Player two

Leave both slots empty to try the included link test. Different games are supported when their original link protocols are compatible. GBA is not supported in this build.

Network settings

Use a TURN server if your networks cannot connect directly. Both peers need the same two ROMs in the same order. The host supplies both starting battery saves.

Ready. Choose cartridges or start the included test.

Click the game to focus. Arrow keys: move · X: A · Z: B · Enter: Start · Shift: Select. A gamepad also works. Local player 2: WASD, G/H, T/Y.

Save downloads are separate for each cartridge. This lab does not upload saves to your RomM library.
